# ~/Harley - Personal Blog

This is my blog, I post about Clean Architecture, Nature, low level programming and anything I find interesting!

## Getting Started
### Prerequisites
[PNPM](https://pnpm.io/)

### Run!
```bash
# Install
pnpm install

# Run in Development mode
pnpm run dev
```

### Stack
* [MDX](https://mdxjs.com/) - Blog content / formatting
* [Astro 7](https://astro.build/) - Static Site Framework
* [TailwindCSS](https://tailwindcss.com/) - Styling
* [Vercel](https://vercel.com) - Automatic Deployment
* [PageFind](https://pagefind.app/) - Search functionality
